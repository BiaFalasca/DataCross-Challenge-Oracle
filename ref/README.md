
# 📚 Referências

Este diretório reúne as referências utilizadas como base para o desenvolvimento do **DataCross**.

As fontes foram utilizadas para apoiar diferentes etapas do projeto, incluindo a compreensão do contexto de saúde pública, análise dos dados, definição da solução, desenvolvimento da arquitetura e utilização das tecnologias empregadas.

Além das referências bibliográficas, este diretório também contém arquivos e materiais utilizados como apoio durante o desenvolvimento do projeto.


## 📂 Materiais de referência

Além das referências bibliográficas, este diretório contém arquivos utilizados como material de apoio para o desenvolvimento do DataCross.

Esses materiais podem incluir documentações, artigos, bases de referência, especificações técnicas e outros conteúdos utilizados durante a construção da solução.

Os arquivos disponíveis neste diretório complementam as referências apresentadas acima e serviram como apoio para as decisões tomadas ao longo do projeto.

---

## 🔎 Utilização das referências

As referências foram utilizadas principalmente para:

- compreender o contexto da saúde pública e da regulação hospitalar;
- apoiar a análise e interpretação dos dados;
- fundamentar decisões relacionadas à solução proposta;
- apoiar o desenvolvimento da arquitetura;
- consultar conceitos e tecnologias utilizadas no projeto;
- orientar o desenvolvimento dos componentes do DataCross.
