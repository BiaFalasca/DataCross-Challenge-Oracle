# DataCross - Inteligência na Regulação Hospitalar

## O Projeto
O DataCross é um sistema de apoio baseado em Processamento de Linguagem Natural (PLN) que lê prontuários médicos automaticamente e identifica pacientes com internação prolongada sem necessidade.

## 📌 Sobre o Projeto

O **DataCross** é uma solução desenvolvida para apoiar a gestão e a regulação de pacientes no sistema público de saúde.

A proposta surgiu a partir do problema da utilização pouco eficiente dos dados disponíveis nos sistemas de saúde e da análise manual e demorada de informações presentes nos prontuários médicos.

O sistema utiliza **Processamento de Linguagem Natural (PLN)** para analisar informações dos prontuários e identificar pacientes que possam estar aptos para transferência ou alta hospitalar.

O DataCross não tem como objetivo substituir os sistemas já utilizados na regulação. A solução funciona como uma **camada inteligente de apoio**, utilizando os dados existentes para automatizar análises e auxiliar os profissionais na tomada de decisão.

---

## 🎯 Problema

O sistema de saúde pública possui grandes volumes de dados provenientes de diferentes fontes, como DATASUS, CNES, CROSS e SIRESP, porém essas informações nem sempre são exploradas de maneira eficiente e em tempo real.

Além disso, a análise de prontuários pode ser um processo manual e demorado, dificultando a identificação rápida de pacientes que já podem ser encaminhados para uma nova etapa do atendimento.

Essa demora pode contribuir para a permanência hospitalar prolongada e para uma menor disponibilidade de leitos para outros pacientes.

---

## 💡 Nossa Solução

O DataCross utiliza técnicas de **Processamento de Linguagem Natural** para analisar automaticamente informações presentes nos prontuários.

A partir dessa análise, o sistema busca identificar pacientes potencialmente aptos para transferência ou alta e sinalizar casos prioritários para a fila de regulação.


> **Observação:** O DataCross não substitui o CROSS ou o SIRESP. Ele atua como uma camada inteligente de apoio à decisão, utilizando os dados existentes para automatizar análises e priorizar casos.
